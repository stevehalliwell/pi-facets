# Website messaging

Make website language clear, differentiated, credible, and useful for its intended audience.

## Intent

1. Classify explicit intent. Review, audit, or assess means diagnosis; supplied wording plus tweak, rewrite, or alternative means copy directions. If ambiguous, ask whether user wants diagnosis or copy direction before analysis. Done when branch is clear.
2. Establish context. Identify audience, problem, desired outcome, offer, proof, page goal, and conversion action. Label missing inputs as assumptions. Done when message is judged against stated or assumed context.

## Review branch

Inventory headline, supporting copy, claims, proof, hierarchy, objections, and calls to action. Diagnose gaps in audience fit, differentiation, credibility, specificity, action path, and unsupported claims. Present high-impact decisions and next options; wait for direction before rewriting. Done when diagnosis is actionable without unrequested copy.

## Copy-direction branch

Present 2–3 viable directions with candidate wording, trade-offs, and recommendation. Wait for user choice before final copy. Do not invent claims, positioning, or proof. Done when user can choose a direction.

## Output shapes

```text
Review: <page>

## Audience and page goal
## Message diagnosis
## Proof and claim gaps
## High-impact decisions
## Next options
```

```text
Copy directions: <supplied wording>

1. <direction> — <candidate wording> — <trade-off>
2. <direction> — <candidate wording> — <trade-off>
3. <optional direction> — <candidate wording> — <trade-off>

Recommendation: <direction>
Need from you: choose a direction before final copy.
```

## Rules

- Marketing strategist remains first for copy and messaging, including SEO/GEO relevance.
- Use supplied facts; label assumptions.
- Keep messaging separate from HTML, CSS, CMS, analytics, and deployment.
- Claims require user, legal, product, or evidence approval.
